# TaskFlow

Aplicación web para gestionar tareas, hecha con HTML, CSS y JavaScript vanilla. Las tareas se guardan en el navegador con `localStorage`.

> Proyecto en desarrollo.

## Requisitos

- Node.js 20 o superior. Solo se usa para el servidor de desarrollo y las pruebas; no hay dependencias que instalar.

## Uso

```bash
npm run dev   # inicia el servidor en http://localhost:3000
npm test      # ejecuta las pruebas con node:test
```
